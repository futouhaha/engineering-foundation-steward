# 给第一次试用的朋友

做一个会持续修改的小工具，换个聊天后，下一位助手怎么知道该从哪版接手？工程基建顾问会先了解你怎么用、有哪些现成的办法、什么资料不能弄丢，再帮你选眼下值得做的准备。一个人用虚构资料，可能只需一个版本副本和几条检查；如果多人会改同一份原件，就该先谈怎么防覆盖、怎么恢复。

从[有限试用发布页](https://github.com/futouhaha/engineering-foundation-steward/releases/tag/v0.1.0-candidate.12.1)下载带 `local.zip` 的 Skill 包并解压。把整个顾问文件夹的位置告诉 Codex，然后说：

> 我想用这个工程顾问看看我的项目。允许只读 <项目目录>。先了解我的用途，再告诉我应该保留什么、补什么、怎样知道做好了，以及不满意怎样停。请在聊天里给方案，先别施工。

你会收到一份分六部分的说明，和一份给实施助手的施工单。由你决定是否批准；批准后由项目自己的助手建设和验证。首次试用选低风险项目，不用开自动提醒。[安装与首次使用](../README.md)
