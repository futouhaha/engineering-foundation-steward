# 0.1.0-candidate.5 · 首次 GitHub 预发布

本次上架不改变 candidate.5 的25个公共 Skill 文件，不新增运行权限或自动安装。源版本固定为0.1.0-candidate.5，具体文件指纹见根目录 SKILL_MANIFEST.json。

## 这一版改进了什么

用户层直接呈现成功结果、失败/暂停、撤回与无法保证恢复的影响；工程方案不能把关键批准条件藏在技术附件里。明确实际启动的 Agent 与测试模拟提交者的区别。普通已批准小改继续处理，不重复审批。

## 验证事实

开发阶段80项单测通过；B/C/D/H2新上下文实际加载，分别覆盖研究工具、多模块项目、高风险方案和普通小改。高风险报告初审发现角色范围和术语问题，经一轮定向返修、新上下文重跑、六问盲读与独立复核通过。失败历史没有被改写成最初就通过。

机械测试、实际 Skill 行为和模型理解是不同证据；不等于真实人类试用，也不证明业务提案已实施。公开复现材料包含两份必需负例和虚构场景生成器，不包含私人开发报告。

## 已知限制

- 真实零基础人类试用未运行；不能保证不同模型或项目都产生同样质量的报告。
- 原生自动发现、Hook持续提醒与 Main 实际行动应分别验证，不能把出现提示当自动完成检查。
- inspect默认不调用Git；明确允许时可开启本根元数据查询，链接或外部Git元数据降级为未知。
- 未完成所有其他用户环境的四模式整链测试；公开候选不依赖私人六文件模板，但实际环境仍需验证。
- 真实数据覆盖、并发保护及恢复必须由目标项目在准确许可下实际实施和验证。

## 下载与复现

版本页提供 Skill ZIP 和独立 reproduction ZIP。前者用于显式读取/经批准安装；后者用于复现机械测试和虚构行为评估。SHA256SUMS 给出附件摘要。

不要把整个复现包复制进 Skill 安装目录。升级时核对版本与差异，不自动覆盖项目规则或继续使用旧的触发验证结论。
